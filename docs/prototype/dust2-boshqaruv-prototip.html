Server manzili

Har bir o'yin kompyuterida DUST2 klient birinchi marta ishga tushganda shu ma'lumotlar qo'lda kiritiladi. Ulangan kompyuter keyingi safar kodsiz ulanadi.

Kompyuterlar

Nomi, zonasi, IP va MAC manzili. MAC manzil orqali kompyuter masofadan yoqiladi (Wake-on-LAN), IP orqali o'chiriladi va qayta yoqiladi.

NomiZonaIP manzilMAC manzilHolatSoatAmallar

Brauzer tarmoqqa to'g'ridan-to'g'ri paket yubora olmaydi, shuning uchun bu prototipda yoqish/o'chirish buyruqlari simulyatsiya qilinadi va jurnalga yoziladi. Kompyuter versiyasida server Wake-on-LAN paketini (UDP 9-port) MAC manzilga yuboradi, o'chirish esa klient agentiga IP orqali boradi. Kompyuterning BIOS va tarmoq kartasida Wake-on-LAN yoqilgan bo'lishi kerak.
